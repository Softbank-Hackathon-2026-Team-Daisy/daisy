- **실서버 배포 생성이 409** — 원인: 로컬에 넣은 테스트 빌드의 `image_refs`가 서버 계약(`{service: {image_ref, digest, commit_sha}}`, digest는 sha256 64자리)과 달랐음 → 테스트 데이터를 고쳐 해결 (웹 문제 아님)
